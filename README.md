## Write-up format
Every write-up follows the same structure:
- **Vulnerability Class** — OWASP category
- **Steps to Reproduce** — exact repro steps
- **Proof of Concept** — evidence the exploit works
- **Impact** — realistic assessment of what an attacker could do
- **Root Cause** — why the vulnerability exists
- **Remediation** — how it should be fixed
